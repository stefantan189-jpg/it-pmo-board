# IT PMO Board

A single-page Kanban board demo for a fictitious bank's internal IT PMO. Vanilla HTML, CSS and JavaScript in one file, no build step. Board state lives in memory only, so a refresh resets the demo data.

Open `index.html` directly, or use the GitHub Pages site for this repository.

To receive email notifications for new tasks, set `FORMSUBMIT_ENDPOINT` at the top of the script in `index.html` and activate it through the confirmation email FormSubmit sends on the first submission.
